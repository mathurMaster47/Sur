# Sur 

Sur is a browser-based devotional reading library. Build a reading sequence from collections or individual stutis, then read page by page with original text, transliteration, or both.

## Library features

- Create multiple collections and assign a stuti to one or more collections.
- Organize stutis by category: Stuti, Aarti, Chalisa, Bhajan, Mantra, or Other.
- Search the library and filter it by category.
- Share public stutis with share links, or publish them through the configured Google Apps Script endpoint.
- Save private stutis and preferences in this browser.

The app is a static client-side site. User data is stored in browser local storage; cloud publishing requires the Google Apps Script endpoint configured in `app.js`.
